Modo de edição

Administração · GitHub

Para editar e publicar, use um token de acesso fino (fine-grained) criado em GitHub → Settings → Developer settings → Personal access tokens, restrito a este repositório, com a permissão Contents: Read and write. O token fica só neste navegador e é enviado somente para api.github.com.

Nova seção

Cria uma seção nova no índice, além das que vêm do livro. Ela fica como rascunho neste navegador até você usar Publicar no GitHub, que grava o arquivo da seção e atualiza o indice.json.

Inserir tabela

Se o bloco onde está o cursor estiver vazio, a tabela toma o lugar dele; se tiver texto, a tabela entra logo abaixo. Depois de criada, a barra que aparece sobre a tabela permite acrescentar ou tirar linhas e colunas e ligar ou desligar as bordas.
